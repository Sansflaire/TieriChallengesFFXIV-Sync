# TieriChallengesFFXIV-Sync

Machine-readable sync data for the FFXIV Miscellaneous Challenges Dalamud plugin.

- `bans.json` — moderation data. Entries are salted hashes with individually encrypted notes; there is nothing human-readable here by design.
- `challenges/` — challenge definitions and their master list.

Edited by the plugin, not by hand.
